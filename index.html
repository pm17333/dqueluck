ข้อควรรู้ก่อนใช้ใน QGIS
  • เปิดที่ Layer › Add Layer › Add/Edit Virtual Layer วางคำสั่งในช่อง Query — ชั้นข้อมูลที่อ้างถึงต้องเปิดอยู่ในโปรเจกต์และชื่อเลเยอร์ต้องตรงกับที่ใช้ในคำสั่ง
  • ระยะทางและพื้นที่คิดตามหน่วยของระบบพิกัด ค่าที่ระบุเป็นเมตรจะถูกต้องเมื่อข้อมูลอยู่ในระบบพิกัดแบบเมตร เช่น EPSG:32647 หรือ 32648
  • ท่อปลอก (functionId = 6) ถูกตัดออกจากคำสั่งที่คิดความยาวท่อทุกคำสั่ง
