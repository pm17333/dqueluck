# ชุดคำสั่งสำหรับส่งให้ Claude Design

คัดลอกข้อความตั้งแต่เส้นคั่นด้านล่างไปวางใน Claude Design ได้เลย
แนบไฟล์ `index.html` และ `queries.js` ไปด้วยจะช่วยให้เห็นของจริง

---

ช่วยออกแบบหน้าเว็บใหม่ให้เครื่องมือภายในตัวหนึ่ง ผมมีของที่ใช้งานได้อยู่แล้วและอยากได้งานออกแบบที่ดีขึ้น โดยตรรกะการทำงานเดิมต้องยังใช้ได้

## เครื่องมือนี้คืออะไร

คลังคำสั่ง SQL สำเร็จรูปสำหรับการประปาส่วนภูมิภาค ผู้ใช้เลือกสาขา เลือกชั้นข้อมูล เลือกคำถามที่อยากได้คำตอบ แล้วกดปุ่มเดียวเพื่อให้ระบบแสดงคำสั่ง SQL ที่เขียนไว้ล่วงหน้า จากนั้นคัดลอกไปวางในเครื่องมือ Virtual Layer ของโปรแกรม QGIS เพื่อรันเอง

เว็บไม่ได้ต่อฐานข้อมูลและไม่ได้รันคำสั่งเอง หน้าที่เดียวคือ ประกอบคำสั่งให้ถูกต้อง แล้วส่งมอบให้คัดลอกได้ง่าย

## ใครใช้

เจ้าหน้าที่ GIS และช่างของสำนักงานประปา 30 สาขา ใช้บนคอมพิวเตอร์ตั้งโต๊ะเป็นหลัก ควบคู่ไปกับหน้าต่าง QGIS ที่เปิดอยู่ข้าง ๆ ผู้ใช้ส่วนใหญ่ไม่ได้เขียน SQL เป็น จึงต้องเข้าใจได้ว่าแต่ละคำสั่งตอบคำถามอะไร โดยไม่ต้องอ่านโค้ด ภาษาที่ใช้ในหน้าเว็บเป็นภาษาไทยทั้งหมด ยกเว้นตัวคำสั่ง SQL

## โครงหน้าปัจจุบัน สามส่วนเรียงจากบนลงล่าง

1. **เลือกสาขาและชั้นข้อมูล** — dropdown เลือกสาขา 30 สาขา ตามด้วยแถบแสดงชื่อตารางจริงที่จะถูกใช้ เช่น `B5541018_PIPE` แล้วต่อด้วยปุ่มชั้นข้อมูล 7 ปุ่ม (BLDG, DMA, FIREHYDRANT, LEAKPOINT, METER, PIPE, VALVE) กดเลือกได้พร้อมกันหลายปุ่ม
2. **เลือกสิ่งที่ต้องการสืบค้น** — dropdown รายการคำถาม ซึ่งจะแสดงเฉพาะคำสั่งที่ผู้ใช้เลือกชั้นข้อมูลครบตามที่คำสั่งนั้นต้องใช้ ใต้ dropdown มีคำอธิบายหนึ่งบรรทัด และปุ่ม Create SQL
3. **ผลลัพธ์** — กล่องแสดงคำสั่ง SQL พร้อมเลขบรรทัดและการเน้นสีไวยากรณ์ มีปุ่มคัดลอกกับปุ่มดาวน์โหลด และมีแถบหมายเหตุใต้กล่องบอกข้อควรระวังของคำสั่งนั้น

## โจทย์การออกแบบ

โครงสามส่วนนี้ผ่านการใช้งานจริงมาแล้วและตอบโจทย์ดี ขอให้คงลำดับขั้นตอนไว้ แต่ปรับปรุงเรื่องต่อไปนี้ได้เต็มที่

- ระบบสี ตัวอักษร ระยะห่าง และบุคลิกโดยรวมของหน้า ตอนนี้ใช้โทนกระดาษแบบแผนที่ช่างสำรวจ ถ้ามีทิศทางที่เหมาะกว่าเสนอมาได้
- ปุ่มเลือกชั้นข้อมูล 7 ปุ่ม ทำอย่างไรให้เห็นชัดว่าอันไหนถูกเลือกอยู่ และเห็นความสัมพันธ์ว่าคำสั่งบางอันต้องใช้หลายชั้นร่วมกัน
- ลำดับความสำคัญของสายตา ตอนนี้ทุกส่วนหนักเท่ากันหมด กล่องคำสั่ง SQL ควรเป็นพระเอกของหน้า
- สถานะว่างเปล่า เมื่อเลือกชั้นข้อมูลแล้วไม่มีคำสั่งที่ตรง ผู้ใช้มักงงว่าต้องทำอะไรต่อ
- การอ่านคำสั่ง SQL ที่ยาว 20 ถึง 30 บรรทัด ให้อ่านง่ายและคัดลอกได้มั่นใจ

## ข้อจำกัดทางเทคนิค

- เป็นเว็บ static ล้วน ไฟล์เดียวจบ ไม่มี backend ไม่มี build step ไม่มี framework ใช้ HTML CSS JavaScript ธรรมดา
- ห้ามใช้ localStorage หรือ sessionStorage
- ต้องคง id ของ element เหล่านี้ไว้ เพราะ JavaScript เดิมผูกกับมันโดยตรง ถ้าเปลี่ยนหน้าตาแต่คง id เดิม โค้ดจะทำงานต่อได้ทันที
  - `branch` (select สาขา), `preview` (แถบชื่อตาราง), `chips` (กล่องปุ่มชั้นข้อมูล), `all` (ปุ่มเลือกทั้งหมด)
  - `q` (select คำถาม), `about` (คำอธิบาย), `qcount` (ตัวนับรายการ), `go` (ปุ่ม Create SQL)
  - `out` (กล่องคำสั่ง), `note` (แถบหมายเหตุ), `trace` (แถบหัวกล่อง), `copy` และ `dl` (ปุ่มคัดลอกและดาวน์โหลด)
- ปุ่มชั้นข้อมูลถูกสร้างด้วย JavaScript แต่ละปุ่มเป็น `<button class="chip" data-layer="PIPE" aria-pressed="true">` ข้างในมี `<b>` ชื่อย่อ และ `<span>` ชื่อไทย ขอให้ออกแบบสไตล์ผ่าน class และ aria-pressed
- กล่องคำสั่งถูกสร้างด้วย JavaScript เป็นสองคอลัมน์ คือ `.gutter` เลขบรรทัด และ `<pre class="code">` ที่มีแต่ละบรรทัดครอบด้วย `<span class="line">` ส่วนการเน้นสีใช้ `<i>` ที่มี class `k` คำสงวน `f` ฟังก์ชัน `s` ข้อความ `n` ตัวเลข

## สิ่งที่อยากได้กลับมา

ไฟล์ HTML ไฟล์เดียวที่ใช้แทนของเดิมได้ พร้อมคำอธิบายสั้น ๆ ว่าตัดสินใจออกแบบแบบนั้นเพราะอะไร ถ้ามีสองทิศทางให้เลือกจะดีมาก
