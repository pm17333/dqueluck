ข้อควรรู้ก่อนใช้ใน QGIS
  • ชื่อตารางประกอบขึ้นจาก B + รหัสสาขา + _ + ชื่อชั้นข้อมูล เช่น B5541018_PIPE โดย 55410 เป็นรหัสตายตัว และสองหลักท้ายคือรหัสสาขา
  • เปิดที่ Layer › Add Layer › Add/Edit Virtual Layer วางคำสั่งในช่อง Query — ชั้นข้อมูลที่อ้างถึงต้องเปิดอยู่ในโปรเจกต์และชื่อเลเยอร์ต้องตรงกับที่ใช้ในคำสั่ง
  • คอลัมน์เรขาคณิตใน Virtual Layer ชื่อ geometry เสมอ ไม่ว่าต้นทางจะเป็นรูปแบบใด
  • ระยะทางและพื้นที่คิดตามหน่วยของระบบพิกัด ค่าที่ระบุเป็นเมตรจะถูกต้องเมื่อข้อมูลอยู่ในระบบพิกัดแบบเมตร เช่น EPSG:32647 หรือ 32648
  • คำสั่งที่มีคอลัมน์ geometry ในผลลัพธ์จะแสดงบนแผนที่ได้ แต่ต้องกำหนด Unique identifier ในหน้าต่าง Virtual Layer ก่อน
  • ไม่ต้องใส่ ; ปิดท้าย และรันได้ครั้งละหนึ่งคำสั่ง
  • yearInstall ในตาราง PIPE เก็บเป็น พ.ศ. คำสั่งเรื่องอายุท่อจึงบวก 543 เข้ากับปีปัจจุบันก่อนนำมาลบ
  • ท่อปลอก (functionId = 6) ถูกตัดออกจากคำสั่งที่คิดความยาวท่อทุกคำสั่ง
